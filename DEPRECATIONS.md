# Deprecations

Ledger of deprecated public APIs across the Python, JavaScript, and Java SDKs.
It follows the deprecation policy in [`STABILITY.md`](./STABILITY.md): a
deprecated API stays for at least one minor release and is removed only in the
next major release (unless a security fix requires faster removal). Removal of
everything listed here for `3.x` and `4.x` is the job of `F-API-02` in
[`docs/roadmap.md`](./docs/roadmap.md) (v5.0).

Add a row in the same pull request that deprecates the API, and mention it in
the `CHANGELOG.md` entry for that release.
